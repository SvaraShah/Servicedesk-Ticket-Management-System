##  **Service Desk (Ticket Management System)**

### **Project Overview**

The **Service Desk TMS** is a professional-grade console application designed to simulate the incident management lifecycle found in **SAP Service Cloud**. It provides a structured environment for logging technical issues, assigning priority levels, and tracking resolution status.

This project demonstrates core **Object-Oriented Programming (OOP)** principles and **Data Persistence** through SQL, tailored for enterprise-level service workflows.

### **Key Features**

* **Incident Logging:** Capture detailed issue descriptions with automated system timestamps.


* **Priority Matrix:** Categorize tickets into High, Medium, or Low to reflect business impact.


**Data Persistence:** All ticket data is stored in a relational **SQLite** database, ensuring information is retained after the application closes.



### **Tech Stack**

* **Language:** Python 


* **Database:** SQL (SQLite) 


* **Architecture:** Object-Oriented Programming (OOP)
